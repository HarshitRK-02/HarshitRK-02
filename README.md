## 🏭 What I'm building

I lead **[Yantrik Infotech](https://github.com/Yantrik-Infotech)**, where we're building **Yantrik MES** — a Smart Manufacturing Execution System for electronics manufacturers.

Before this I worked inside an EMS company on the **SMT line and the warehouse**, and learned the **NPI** process end to end. That's the problem we're solving: giving the shop floor real-time traceability, line visibility and clean data, without the clipboards and spreadsheets.

```text
  Warehouse ──► SMT line ──► Assembly ──► Test ──► Dispatch
      │            │            │          │          │
      └────────────┴──── Yantrik MES ──────┴──────────┘
                 traceability · OEE · real-time dashboards
```
